## 🔨 Featured Projects

I enjoy building projects that go beyond basic CRUD applications, focusing on real engineering challenges such as **distributed communication, concurrency, data integrity, and AI-powered information retrieval**.

### ⚡ FlashSale — High-Concurrency Backend

A Spring Boot backend designed to handle flash-sale traffic while preventing inventory overselling.

- Focuses on race conditions and concurrent inventory reservations.
- Uses PostgreSQL transactions and Redis as part of the backend architecture.
- Explores idempotency, reservation expiration, and inventory recovery.
- Emphasizes reliable order-state transitions and data consistency.
- Designed to be load-tested under high concurrent request volumes.

**Tech Stack:** Java, Spring Boot, PostgreSQL, Redis, Maven

### 🔗 Shorty — Microservices-Based URL Shortener

A URL shortening platform built to explore distributed backend architecture and service-to-service communication.

- Separate authentication, URL management, and analytics services.
- Service discovery and routing using Eureka and Spring Cloud Gateway.
- PostgreSQL persistence and Redis caching.
- Kafka-based click-event processing in the architecture.
- React frontend integrated with backend APIs.

**Tech Stack:** Java, Spring Boot, Spring Cloud, Eureka, API Gateway, PostgreSQL, Redis, Kafka, React

### 📈 TradeVault — Full-Stack Trading Journal

A trading journal application designed to help users record and review their trades.

- REST API development using Node.js and Express.js.
- MongoDB and Mongoose for trade data persistence.
- Authentication and protected API workflows.
- Trade records with entry/exit details, risk management information, notes, and screenshots.
- Cloud-based image storage integration.

**Tech Stack:** Node.js, Express.js, MongoDB, Mongoose, React, JWT
